# Безопасность

## Модель угроз (кратко)

Приложение обрабатывает **голос и переписку пользователя** — это чувствительные данные. Плюс оно поднимает
HTTP/WebSocket-сервер на машине, где одновременно открыт браузер с произвольными сайтами.

| Угроза | Вектор | Защита |
|---|---|---|
| Сайт в браузере читает транскрипт или управляет приложением | `fetch`/WebSocket на `127.0.0.1:7811`, DNS rebinding | проверка `Host` (только `127.0.0.1:<port>` / `localhost:<port>` / `[::1]:<port>`), проверка `Origin` для WS и API, CORS выключен, токены |
| CSRF на управляющее API | форма или `fetch` с чужого сайта | admin-токен только в заголовке `Authorization` (не cookie); изменения — только `POST/PUT/DELETE` с `application/json` |
| Доступ из локальной сети | бинд на `0.0.0.0` | по умолчанию только `127.0.0.1`; LAN — явная опция с предупреждением, отдельным токеном и allowlist IP |
| XSS через распознанный текст | речь или текст содержит `<script>` | оверлей вставляет текст только через `textContent`; строгий CSP без `unsafe-eval` |
| Вредоносная пользовательская тема | CSS с `url(http://…)` для утечки данных | CSP `img-src 'self' data:; font-src 'self' data:; connect-src 'self'`; темы — только CSS |
| Подмена модели при скачивании | MITM, скомпрометированный репозиторий | HTTPS (rustls) + **закреплённый SHA-256** каждого файла в манифесте; при несовпадении файл удаляется; форматы без исполняемого кода (GGML/GGUF, CTranslate2, ONNX, safetensors) |
| Вредоносный файл модели | эксплойт парсера C++-движка | только файлы из каталога с закреплёнными хэшами; движки обновляются по advisories |
| Path traversal | имя темы, модели или источника вида `../../` | пути строятся от базовой папки; имена валидируются regex; после `canonicalize` проверяется `starts_with(base)` |
| Утечка секретов | пароль obs-websocket в конфиге или логах | Windows Credential Manager (`keyring`); токены и пароли не логируются; тип `Secret<T>` без `Debug`/`Display` |
| Утечка транскриптов | телеметрия, сторонние API | **ноль сетевых запросов**, кроме скачивания моделей с согласия пользователя и loopback (OBS, локальная LLM) |
| Сторонний плагин | внешний плагин — это чужой код | DLL-плагинов нет; внешние плагины — отдельные процессы в Job Object (лимиты, kill-on-close), позже — AppContainer; сторонние плагины выключены по умолчанию; при включении показывается манифест |
| Плагин обходит защиту сервера | output-плагин открывает свой порт | веб-части только через `WebMount` ядра под `/o/<id>/` с общими проверками; встроенным плагинам открывать сокеты запрещено |
| Ошибки памяти | `unsafe`, FFI с C++-движками и WinAPI | `unsafe` только в FFI-обёртках с `// SAFETY:`; `#![forbid(unsafe_code)]` во всех остальных крейтах; паники перехватываются на границе потока |
| Цепочка поставок | crates.io, GitHub Actions | `Cargo.lock` в репозитории, `cargo-deny` (лицензии, advisories, только crates.io), `cargo-audit`; actions закреплены по SHA; подписанные релизы, SBOM, контрольные суммы |

## Токены
- `admin-token` — управление и настройки. 32 байта из ОС-генератора (`getrandom`), base64url, хранится в Credential Manager.
  Ссылка на UI с токеном открывается из трея.
- `read-token` — только чтение событий (оверлей, WS). Его можно вставить в OBS; при утечке перевыпускается одной кнопкой.
- Сравнение токенов — за постоянное время (`subtle::ConstantTimeEq`).

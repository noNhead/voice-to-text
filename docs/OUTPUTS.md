# Форматы вывода

Каждый формат вывода — это **output-плагин** (контракт — в [PLUGINS.md](PLUGINS.md#output--вывод)).
Ниже описаны встроенные плагины: `ws-stream`, `text-file`, `obs`, `overlay`, `transcript-log`.
Все они получают один и тот же поток событий (см. [ARCHITECTURE.md](ARCHITECTURE.md#перевод-и-события)).
Каждый выход включается отдельно, и для каждого можно выбрать, какие источники он показывает.
Свой формат (например, отправку в чат-бота или в субтитры другой программы) можно добавить своим output-плагином.

## 1. Трансляция / стриминг текста

Три способа. Пользователь выбирает тот, что подходит под его программу.

### 1a. WebSocket JSON-поток
`ws://127.0.0.1:7811/ws/events?token=<read-token>` отдаёт события `segment` / `status` / `clear`.
Подходит для своих интеграций, ботов и других программ.

### 1b. Текстовый файл (OBS «Текст → Читать из файла»)
`<data_dir>/live/current.txt` перезаписывается **атомарно** (запись во временный файл + `ReplaceFileW`/`MoveFileExW`),
поэтому OBS никогда не прочитает файл наполовину записанным. Настройки:
- `lines` — сколько последних строк держать (по умолчанию 2);
- `show` — `dst` | `src` | `both`;
- `clear_after_s` — очистить файл после N секунд тишины;
- отдельный файл на каждый источник: `live/<source_id>.txt`.

### 1c. obs-websocket v5
- **Closed captions**: `SendStreamCaption` отправляет CEA-608 подписи в поток (их понимают
  Twitch и YouTube). Отправляются только финальные сегменты, текст режется под ограничения 608 (32 символа × 4 строки).
- **Текстовый источник**: `SetInputSettings` для GDI+/FreeType2 источника, имя источника задаётся в настройках.
- Пароль obs-websocket хранится в Windows Credential Manager.

## 2. Браузерный вывод (оверлей) с настройкой внешнего вида

`http://127.0.0.1:7811/o/overlay/?token=<read-token>&theme=default`

Используется как **Browser Source в OBS** или в обычной вкладке/окне браузера (например, на втором мониторе
во время звонка).

### Параметры URL (переопределяют настройки темы)
| Параметр | Пример | Описание |
|---|---|---|
| `theme` | `default`, `minimal`, `karaoke`, `chat` | готовая тема |
| `sources` | `mic,discord` | какие источники показывать |
| `show` | `dst` / `src` / `both` | что выводить |
| `lines` | `2` | максимум строк на экране |
| `partial` | `1` / `0` | показывать ли частичный текст (нестабильный хвост — полупрозрачным) |
| `fade_s` | `6` | через сколько секунд строка исчезает |
| `align` | `center` / `left` | выравнивание |

### Кастомизация
- Темы — это CSS-файлы на **CSS-переменных** (`--font-family`, `--font-size`, `--color-text`,
  `--color-stroke`, `--stroke-width`, `--bg`, `--line-gap`, `--anim-in`…).
- В UI настроек есть **визуальный редактор с живым превью**. Результат сохраняется как пользовательская тема
  в `<config_dir>/themes/<name>.css`.
- Пользовательский CSS **только CSS**: JS в темах запрещён, страница отдаётся с жёстким CSP (см. SECURITY.md).
- Фон прозрачный по умолчанию, чтобы оверлей сразу работал в OBS.

## 3. Текстовый лог с временем в часовом поясе пользователя

Папка: `<data_dir>/transcripts/YYYY-MM-DD/`. Новый файл на каждую сессию запуска.
Часовой пояс — системный (`tzlocal`) или заданный в конфиге (`timezone = "Europe/Moscow"`).
Пишутся **только финальные** сегменты.

### `.txt` — для человека
```
[2026-11-16 14:03:12 MSK] (mic) RU: Привет, сегодня мы посмотрим новую игру.
                                EN: Hi, today we'll take a look at a new game.
[2026-11-16 14:03:20 MSK] (discord) EN: Looks great!
                                    RU: Выглядит отлично!
```

### `.srt` / `.vtt` — субтитры к записи видео
Время считается **относительно начала сессии**. Это позволяет наложить субтитры на запись OBS,
начатую одновременно с сессией. Есть кнопка «синхронизировать с началом записи OBS» (через obs-websocket
событие `RecordStateChanged`).

### `.jsonl` — для машин
Одно событие `segment` (final) на строку, в формате из ARCHITECTURE.md.

### Хранение
- Опция `retention_days` (по умолчанию выключена — ничего не удаляется).
- Логи — это личные данные. Они лежат только локально, нигде не синхронизируются, и в UI есть
  кнопка «удалить всё».

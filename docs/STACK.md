# Технологический стек и обоснование

Каждое решение проверено по четырём правилам проекта:
**(1) бесплатно и open source** (и модели разрешают коммерческое использование), **(2) локально**,
**(3) качество**, **(4) мало ресурсов**.

**Язык — Rust. Первая платформа — Windows 10 (2004+) / 11.** Linux и macOS — после стабильной версии для Windows;
платформенный код с самого начала изолирован в отдельных крейтах.

## Почему Rust

Задача — не «чтобы работало», а приложение, которое работает рядом с игрой, OBS и звонком и почти не
заметно по ресурсам. Rust даёт:
- **Предсказуемую задержку.** Нет GC и GIL. Аудиопоток работает в реальном времени без пауз.
- **Минимальную базовую стоимость.** Один нативный `.exe`, без интерпретатора. RAM без моделей — единицы мегабайт, запуск мгновенный.
- **Прямой доступ к API Windows** (WASAPI, Process Loopback, MMCSS, EcoQoS) через официальный крейт `windows`. Отдельные хелперы на других языках не нужны.
- **Безопасность памяти.** Мы разбираем аудио, сетевые запросы и файлы моделей, и Rust защищает это без потери скорости.
- **Простое распространение.** Один подписанный бинарник плюс модели, которые скачиваются отдельно.

Цена: меньше готовых ML-обёрток и сложнее сборка C++-движков (whisper.cpp, CTranslate2). Мы её принимаем
и снижаем риск: каждый движок — отдельный плагин-крейт, его можно заменить.

## Распознавание: whisper.cpp по умолчанию

- Один движок покрывает **CPU, NVIDIA (CUDA) и AMD/Intel (Vulkan)**. На Windows это все видеокарты.
- Квантизованные модели GGML (q5_0, q8_0) экономят RAM и VRAM.
- `whisper-rs` — тонкая обёртка над C API whisper.cpp; сам движок развивается быстро.
- Сборка требует **LLVM/clang** (для bindgen) и CMake; для CUDA — CUDA Toolkit, для Vulkan — Vulkan SDK.
  В релизах всё это уже собрано, пользователю ставить ничего не нужно.
- CTranslate2 (`ct2rs`) на CPU с int8 бывает быстрее. Поэтому в фазе 0 сравниваем оба движка на одинаковых WAV
  и выбираем профиль по умолчанию **по замерам**.

Профили (выбор по железу, можно переопределить):

| Профиль | Железо | ASR-модель | Квантизация |
|---|---|---|---|
| `eco` | слабый CPU / ноутбук | `whisper-base` | q5_0 / int8 |
| `balanced` | CPU от 6 ядер | `whisper-small` | q5_0 / int8 |
| `quality` | GPU от 4 ГБ VRAM | `whisper-large-v3-turbo` | q5_0 / fp16 |
| `max` | GPU от 8 ГБ VRAM | `whisper-large-v3` | fp16 |

Whisper сам переводит **с любого языка на английский** (`translate`), поэтому для X→EN отдельная модель перевода не нужна.

## Перевод: только модели с коммерческой лицензией

Аудитория — стримеры с монетизацией, авторы видео, рабочие звонки. Поэтому в каталоге **только модели, разрешающие
коммерческое использование** (политика — в [PLUGINS.md](PLUGINS.md#лицензионная-политика-моделей)). NLLB-200 и
Seamless (CC-BY-NC) не поддерживаются.

| Профиль | Модель | Лицензия | Комментарий |
|---|---|---|---|
| `eco` / `balanced` | **Opus-MT** (Marian) | CC-BY-4.0 | 75–300 МБ на пару, очень быстро на CPU; пивот через EN |
| fallback | **M2M100-418M** | MIT | 100 языков одной моделью — для пар, которые не покрывает Opus-MT |
| `quality` | **M2M100-1.2B** / **MADLAD-400-3B-MT** | MIT / Apache-2.0 | лучше качество, MADLAD рассчитан на GPU |
| `max` | **локальная LLM** (Qwen2.5-7B-Instruct, Mistral-7B-Instruct) | Apache-2.0 | лицензию проверяем для каждой модели |

Все три модели перевода работают на CTranslate2, поэтому это **один плагин и много моделей**.

## Оптимизации под Windows (проверяются замерами)

- Аудиопоток — **MMCSS** (`AvSetMmThreadCharacteristicsW("Audio")`), WASAPI в event-driven режиме, без аллокаций.
- Потоки инференса — пониженный приоритет. Процесс — `BELOW_NORMAL_PRIORITY_CLASS`, чтобы игра и OBS выигрывали конкуренцию за CPU.
- **EcoQoS** (`ProcessPowerThrottling`) для фоновых потоков: сервера, выводов, мониторинга. Для инференса —
  только если замеры не покажут рост задержки.
- В тишине работает только VAD (~0.1 мс на 32 мс аудио). Модели не вызываются.
- Модели выгружаются после N минут простоя, VRAM освобождается.
- Tokio: `current_thread` или максимум 2 воркера. Весь тяжёлый код работает в выделенных потоках, а не в пуле tokio.
- Сборка релиза: `lto = "fat"`, `codegen-units = 1`, `panic = "abort"` в бинарнике, `target-cpu` не задаём
  (нужна совместимость), но whisper.cpp сам выбирает AVX/AVX2/AVX-512 во время работы.
